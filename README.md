## 一、工业控制基础（13 项）

| 术语（英文/缩写） | 中文全称 | 简要说明 |
|------------------|---------|---------|
| **PLC** | 可编程逻辑控制器 | 工业环境中的实时控制核心，采用循环扫描模型，通过 I/O 处理传感器与执行器 |
| **PAC** | 可编程自动化控制器 | PLC 的进化版，支持多语言编程（C++、结构化文本），桥接控制与 IT 系统 |
| **SCADA** | 监控与数据采集系统 | 上位机软件，聚合全厂实时数据，实现可视化监控、报警管理和历史记录 |
| **HMI** | 人机界面 | 本地操作面板，供操作员监控参数、调整设定或紧急停机 |
| **RTU** | 远程终端单元 | 用于偏远站点（管线、泵站）的微处理器设备，支持低功耗无线遥测 |
| **VFD** | 变频驱动器 | 通过改变电机输入频率和电压来控制转速，是预测性维护的数据来源 |
| **CNC** | 计算机数控 | 机床数字化控制技术，用于精密加工 |
| **DCS** | 分布式控制系统 | 流程工业（化工、电力）的分散控制架构 |
| **MES** | 制造执行系统 | 车间层生产执行管理，衔接 ERP 与现场设备 |
| **ERP** | 企业资源计划 | 企业级资源管理系统，涵盖财务、供应链、人力资源等 |
| **PID 控制器** | 比例-积分-微分控制器 | 经典闭环控制算法，广泛用于过程调节 |
| **运动控制器** | 运动控制器 | 专门控制伺服/步进电机的位置、速度和扭矩 |
| **机器人控制器** | 机器人控制器 | 工业机器人的“大脑”，负责轨迹规划与动力学运算 |

## 二、工业网络与通信（16 项）

| 术语（英文/缩写） | 中文全称 | 简要说明 |
|------------------|---------|---------|
| **Ethernet/IP** | 工业以太网协议 | 基于 CIP 的工业以太网标准，广泛应用于离散制造 |
| **PROFINET** | PROFINET | 西门子主导的工业以太网标准，支持实时通信 |
| **Modbus** | Modbus 协议 | 串行通信协议（RTU/ASCII/TCP），设备兼容性极高 |
| **EtherCAT** | EtherCAT 以太网控制自动化技术 | 高性能实时以太网，刷新周期可达微秒级 |
| **Profibus** | Profibus 现场总线 | 过程现场总线，分为 DP（设备）和 PA（过程） |
| **CANopen** | CANopen 协议 | 基于 CAN 总线的上层协议，常用于运动控制 |
| **DeviceNet** | DeviceNet 设备网 | 基于 CAN 的开放式现场总线，面向工业设备 |
| **CC-Link** | CC-Link 现场总线 | 三菱主导的开放式网络，广泛用于亚洲工厂 |
| **BACnet** | BACnet 楼宇自动化控制网络 | 暖通空调及楼宇自控的标准通信协议 |
| **OPC UA** | 开放平台通信统一架构 | 平台无关、安全可扩展的 M2M 通信标准 |
| **TSN** | 时间敏感网络 | 确定性以太网增强技术，保障实时数据流 |
| **SPE** | 单对线以太网（IEEE 802.3cg） | 一对双绞线即可传输数据+供电，最远 1000 米 |
| **工业光网** | 全光工业网络 | 基于光纤的工业网络，与 5G、TSN 融合组网 |
| **5G 专网** | 工业 5G 独立专网 | 企业独立建设核心网和接入网，不依赖公网 |
| **MQTT** | MQTT 协议 | 轻量级发布/订阅消息协议，适合物联网 |
| **CoAP** | 受限应用协议 | 适用于资源受限设备的物联网协议 |
